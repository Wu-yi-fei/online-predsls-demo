# O-PredSLS

**Online System-Level Synthesis for Prediction-Adaptive Networked Control**

Yifei Wu · [Tongxin Li](https://tongxin.me/) · [Jing Yu](https://jingyu.io/)

[Project website](https://wu-yi-fei.github.io/online-predsls-demo/) | **Paper** (forthcoming) | [Demo](https://wu-yi-fei.github.io/online-predsls-demo/demo.html) | [Materials](https://wu-yi-fei.github.io/online-predsls-demo/supplementary_materials.pdf)

O-PredSLS learns predictive closed-loop responses online to adapt to heterogeneous disturbance-prediction errors, while keeping the causal feedback controller fixed.

This repository hosts the project website and an interactive voltage-regulation demo. The demo compares voltage trajectories and quadratic control costs, and uses learned direct prediction gains to select communication links under a prescribed budget.
