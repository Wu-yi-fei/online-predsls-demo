Predictive control on a feeder

This edition transfers the original Python experiment's windowed ridge update, predictive-response update and communication score to the existing interactive feeder. It retains the demo's physical network, inverter dynamics, fixed feedback, actuator limits and offline synthesis objective. It is not a trajectory-level reproduction of the paper's fully actuated voltage experiment.

Bus 1 is fixed at 1 pu. Voltage follows the original LinDistFlow sensitivities on 12.47 kV and 1 MVA bases. Each inverter has a two-second response time, a 120 kVA rating and a reactive command bound of ±70 kvar. Samples are one second apart. The larger network consists of two reference branches sharing the slack. Absolute costs sum over the network and are not directly comparable across sizes.

Prediction and online update

The default demand and solar cycle and correlated background retain their original generators. Forecasts estimate voltage forcing. The five-sample preview includes the current action; a target-t forecast is sealed at max(0, t − 4) and revealed at state t + 1. Later changes to source reliability cannot rewrite an issued message. Manual power disturbances remain unforecast.

Online SLS and scalar adaptation use the same mean loss, the same revealed data and the same regularization. With f denoting a forecast and y its observed forcing, the update is

Cₜ = arg minC (1/m) Σq ∈ Wₜ ‖yq − Cfq‖² + λ‖C − I‖F²
λ = 1.2725674932370515 × 10−5 · m ≤ 60 · first update: action 30

Online SLS uses a full matrix; scalar adaptation restricts C = cI in this same objective. The scalar regularizer is therefore nλ(c − 1)², where n is the number of nonslack states. Before the first update, C = I. Source-quality labels are excluded from the fit.

Φ̂xt,k = Φ̂x,offt,kCₜ   ·   Φ̂ut,k = Φ̂u,offt,kCₜ
Lt,k = Φ̂ut,k − KΦ̂xt,k

The command breakdown uses the actual row L executed at that action. It sums the inspected raw source, other prediction messages and feedback before the actuator limit. The online fit adds no affine projection or support-compatible correction mask. The separate completed-row delayed-gradient diagnostic in the source does not drive this controller.

Two experiments

Communication topology: discovery uses dense messages and accumulates Sij = Σt,k|Lt,k,ij|², without time averaging. The highest-scoring remote sources are retained under the fixed per-receiver budget; local sources are mandatory. Learned and fixed supports each receive a new solve of the existing offline quadratic program. An independent comparison then uses fixed Learned sparse, Fixed sparse, Dense prediction and Feedback only controllers.

Prediction adaptation: Online SLS and scalar adaptation retain dense messages, alongside fixed prediction and feedback only. Discovery candidates are diagnostic; the comparison matrix displays all actually permitted prediction sources. The fresh comparison resets state, accumulated cost, correction and training history. Adaptation restarts at action 30 using only observations from that new trial.

Offline synthesis retains the demo's finite response support, initial conditions and terminal Riccati cost. It is not replaced by the paper's fully actuated model. All controllers share physical disturbances, raw forecasts, feedback, objective and equipment limits. The stated regularization is transferred without tuning for display performance. No controller is guaranteed to win under every error pattern or attack.

Costs and evidence

Commands in the objective are in per unit on the 1 MVA base; the interface reports kvar. Live curves sum actual stage costs. Finite-horizon validation also reports the terminal Riccati penalty. Voltage and cost are not clipped; inverter saturation remains part of the executed dynamics. The 0.95–1.05 pu band is illustrative, not an enforced state constraint.

The current local validation report identifies checked equations, experimental conditions and source fingerprints. Upstream benchmark files belong to the previous algorithm and are not current performance evidence. The old numerical overview has therefore been removed. The Chinese README records the adaptation and reproduction scope.

Current saves use schema 14 and algorithm identifier opredsls-window-ridge-v1. Older saves remain under their previous storage key and are not replayed by the new algorithm. Viewing history, changing chart visibility or changing playback speed does not alter recorded physical samples.

This is a constructed, balanced feeder. LinDistFlow omits line losses and the demo does not model protection, frequency, thermal line limits or battery energy limits. The page runs locally without external scripts or data.
